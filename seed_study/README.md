# Полные раны EML по сидам ГА, без исключений

Зачем: результаты EML сильно зависят от сида ГА, а батч до этого оценивал на
TEST только победителя по VAL, так что плохие сиды в отчёт не попадали. Здесь
каждый сид проходит **полный пайплайн диплома (DATA → GAME-фаза, полный бюджет
из config)** и оценивается на одних и тех же 30 TEST-играх. В статистику
входят все сиды, ни один не выброшен.

## Итог

| задача | оракул на TEST | EML, все сиды (среднее ± std) | 95 % ДИ | медиана | худший / лучший | сидов ниже 80 % потолка | узлов |
|---|---|---|---|---|---|---|---|
| Tetris (линии, лимит 300 фигур, потолок ≈120) | 113.3 | **111.5 ± 12.0** (98.4 % оракула) | ± 8.5 | 115.4 | 78.1 / 117.9 | 1 из 10 | 31 |
| Flappy Bird (трубы, лимит 5000 кадров = 55) | 55.0 | **50.5 ± 6.6** (91.8 % оракула) | ± 4.7 | 53.1 | 33.9 / 55.0 | 1 из 10 | 20 |

Для сравнения, в `distill_compare/REPORT.md` (PR #2) полный пайплайн стоял на
урезанном бюджете и мало сидах: Tetris 97.9 ± 24.4 (3 сида), Flappy 25.2 ± 26.7
(5 сидов, популяция 150, 80 поколений). При полном бюджете разброс по сидам
меньше в 2–4 раза, а среднее выше. Плохие сиды всё равно бывают (Tetris s23,
Flappy s1), поэтому в отчётах надо приводить среднее по всем сидам, а не
лучшего.

**VAL плохо отбирает сиды.** В Tetris сид 23 набирает на VAL 115.9, а на
TEST 78.1. Во Flappy VAL играется с лимитом 3000 кадров (`GA_MAX_FRAMES`), где
потолок 32 трубы, и 9 сидов из 10 упираются в него с одинаковым VAL = 32.0, так
что отбор по VAL среди них, по сути, случайный. Это стоит либо оговорить в
дипломе, либо поднять лимит кадров для VAL.

## Что откуда

**Tetris.** Оракул и датасет те же, что у твоего батча от 2026-08-20
(`runs/2026-08-20_00-50-20_distill_batch`, оракул 100.7 линий при обучении,
113.3 на TEST, config_hash 35edcf8759c3, совпадает с текущим config).
* Сиды 20–24: формулы того батча, переоценённые на TEST
  (`results/legacy/tetris_2026-08-20_batch/`).
* Сиды 25–29: новые раны тем же кодом (`eml-seed-discipline`, 940e777) на
  том же датасете (`results/tetris_o0820/`).
* Проверка совместимости: сид 20, перезапущенный здесь, дал ту же VAL 118.375,
  что и в батче от 20.08 (`results/tetris_o0820/repro_seed20_log.txt`), а
  победитель батча на TEST дал 116.37, ровно как в его summary.json.

**Flappy.** `benchmark.py` сам ничего не сидирует и на каждом ране переобучает
GA-оракула, поэтому его раны смешивают шум оракула с шумом ГА. Здесь оракул
зафиксирован (`models/best_ga.pt`, 55.0 на TEST), датасет собран один раз
(500 эпизодов), меняется только сид ГА (0–9). Штраф medium, популяция 500,
500 поколений, patience 100 (все сиды остановились по плато на поколениях
161–342). Код: ветка с PR #1 (векторизованный DATA-фитнес, те же значения).

**Старые раны (история, в итог не входят).**
* Tetris, батч от 2026-07-12: старая схема, где сид и гиперпараметры менялись
  вместе. TEST: 77.6, 115.8, 113.6, 108.6, 111.5 → 105.4 ± 15.8.
* Flappy, раны `benchmark.py` от 2026-05-29 и 2026-08-19 (у каждого рана свой
  оракул; weak/medium/strong): 42.1–55.0 → 48.4 ± 4.8. Раны от 19.08
  воспроизводятся на TEST один в один.

Полные таблицы по каждому сиду лежат в [TABLES.md](TABLES.md).

## Как повторить

```bash
# Tetris: один сид = один процесс; датасет = results/eml_dataset.npz батча
EML_CODE_ROOT=<checkout eml-seed-discipline> python seed_study/tetris_seed.py \
    --seed 25 --dataset seed_study/data/tetris_o0820.npz --out seed_study/runs/tetris_o0820
# Flappy
python seed_study/flappy_seed.py --seed 0 --out seed_study/runs/flappy_bestga
# старые формулы на текущем TEST, затем сводка
python seed_study/rescore_legacy.py
python seed_study/aggregate.py
```

Батч в `tetris/pipeline.py` теперь тоже оценивает на TEST каждый сид:
`per_config` содержит `test_mean/test_std/test_min/test_max` по всем сидам, а
`main.py distill --batch` печатает их рядом с VAL.
