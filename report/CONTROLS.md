## Выводы

1. **Работает GAME-фаза, то есть поиск политики прямо по очкам.** Без потолков формулы в Tetris вдвое обходят своего оракула (305–328 против 154.5 линий). Методы, которые только имитируют оракула, на средних задачах дают 0–68%.
2. **Оракул почти не нужен.** Контроль без оракула не хуже полного пайплайна в Tetris (328 против 305), во Flappy (40.5 против 38.7) и на трёх из четырёх средних задач. Заметная польза есть только на самой сложной, Forager: 63 против 44. Это символьный policy search с опциональным тёплым стартом, а не дистилляция.
3. **У EML нет преимущества перед классическим базисом.** В Tetris одинаково (305.0 и 305.0), во Flappy классика лучше (53.9 против 38.7), на всех средних задачах классика лучше. Классические формулы при этом считаются быстрее (на средних задачах в 2–2.5 раза), а трансцендентных операций в них 4–5 против 22–35 у EML.
4. **Разброс между сидами огромный.** В Tetris от 44 до 594 линий, на Forager ±26–33 п.п. Поэтому средние по 10 сидам при таком разбросе различают только крупные эффекты. Разница EML и классики в Tetris статистически неразличима.

## Замечания ревью, которые не исправлены (только описаны)

- PPO-тренер считает обрыв на 1000 ходов терминальным состоянием. Вероятно, отсюда слабая игра Tetris-оракула на длинном горизонте и то, что формулы его обходят.
- В Tetris запасной выбор между GAME- и DATA-результатом сравнивает максимум из 40 оценок с одной оценкой. Сравнение смещённое.
- Подпись чекпоинта не включает clamp и eps.
- В distill_compare (PR #2) бюджеты неравные: у полного пайплайна намного больше, число сидов разное (5 против 3). Детерминированные baseline показывали нулевой разброс, потому что данные были фиксированы. В средних задачах это исправлено: у каждого сида свои данные.

## Исправления, найденные по ходу

- No-oracle контроль в Tetris падал на втором поколении: «иммигранты» мутировали несуществующее дерево. Исправлено, добавлен тест `tetris/tests/test_nooracle_game.py`, который падает на старом коде. 4 упавших сида пересчитаны.

## Как воспроизвести

```
# Tetris garbage (оракул tetris/models/garbage_ppo.pt, датасет seed_study/data/tetris_garbage.npz)
cd tetris && EML_TETRIS_ENV=garbage python ../seed_study/tetris_seed.py --seed 20 \
    --dataset ../seed_study/data/tetris_garbage.npz --out ../seed_study/runs/tetris_garbage_eml [--basis classic | --no-oracle]
# Flappy ramp
EML_FLAPPY_ENV=ramp python seed_study/flappy_seed.py --seed 0 --out seed_study/runs/flappy_ramp_eml \
    --oracle flappy_bird_with_ai/models/ramp_ga.pt [--basis classic | --no-oracle]
# средние задачи
python -m medium_tasks.run --task forager --seed 0
python report/make_controls.py > report/CONTROLS_TABLES.md
```
